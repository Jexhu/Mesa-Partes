# Sistema de Mesa de Partes Digital

Aplicación de escritorio en Python para gestión de trámites documentarios.


## Base de Datos
- Persistencia local mediante SQLite (mesapartes.db).


## Interfaz Grafica
- Construida en Python con Tkinter.


## Busqueda de Tramites
- Consulta por DNI y numero de expediente.


## Requisitos
- Python 3.x e instalacion de librerias estandar.
